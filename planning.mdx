# The Actual Python MCP Layer

Conceptually, the server is very simple.

You have:

```text
MCP Server
    │
    ├── Tool
    ├── Tool
    ├── Tool
    ├── Resource
    └── Resource
```

A tool might look conceptually like:

```python
@mcp.tool()
async def autheo_get_balance(address: str) -> dict:
    """
    Get the native THEO balance for an Autheo address.
    """
    
    balance = await rpc.get_balance(address)

    return {
        "address": address,
        "balance_theo": balance
    }
```

Then another:

```python
@mcp.tool()
async def autheo_compute_search(
    cpu: int,
    ram_gb: int,
    storage_gb: int,
    max_price_theo: float | None = None
) -> list[dict]:

    return await marketplace.search(
        cpu=cpu,
        ram_gb=ram_gb,
        storage_gb=storage_gb,
        max_price_theo=max_price_theo
    )
```

The AI doesn't need to know your database schema.

It just sees:

```text
autheo_compute_search
```

with a structured schema.
